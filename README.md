# Space Shooter Ultimate — Android

Canal público de distribuição dos APKs de teste do jogo.

## Download

[Baixar a versão mais recente](https://github.com/escritor2/space-shooter-ultimate-releases/releases/latest)

Na página da versão, abra **Assets** e baixe o arquivo `.apk`.

## Atualizar pelo jogo

1. Instale a versão **0.2.1 ou superior** uma vez para ativar o canal de atualizações.
2. Nas próximas versões, abra **Preferências → Verificar atualizações** no jogo.
3. Confirme o download e a instalação quando o Android solicitar. Se necessário, autorize a instalação desta fonte.

Instale por cima da versão anterior para preservar o progresso. Não é necessário desinstalar o jogo.

O app verifica o hash SHA-256, a versão, o pacote e a assinatura antes de abrir o instalador do Android. Não há instalação silenciosa.

[Arquivo do canal de atualizações](https://github.com/escritor2/space-shooter-ultimate-releases/releases/latest/download/update.json)

## Sobre esta distribuição

Os APKs atuais são versões de teste, assinadas com a mesma chave debug usada nas versões anteriores deste projeto. Este repositório distribui os APKs e os metadados de atualização; o código-fonte é mantido separadamente.
